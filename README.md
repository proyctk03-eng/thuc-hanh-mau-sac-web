# [Bài tập] Tạo Landing Page với Bootstrap và Hình Ảnh

Dự án Landing Page hiện đại, đáp ứng đầy đủ (responsive) được xây dựng theo chuẩn **Bootstrap 5**:
- **Banner / Hero Section:** Tự xây dựng bằng các lớp utility của Bootstrap 5 (`container`, `py-5`, `text-center`, `lead`, `btn-lg`, `rounded-pill`) thay thế cho component `.jumbotron` đã bị loại bỏ.
- **Giới thiệu (About):** Bố cục 2 cột với hình ảnh minh họa chất lượng cao sử dụng lớp `img-fluid` và nội dung mô tả doanh nghiệp.
- **Tính năng (Features):** Bố cục lưới 4 cột (`col-12 col-md-6 col-lg-3`) kèm icon badge, tiêu đề và mô tả ngắn.
- **Nút Kêu gọi Hành động (CTA):** Khối CTA nổi bật với nền gradient, tiêu đề thu hút và nút `btn-light btn-lg`.
- **Footer:** Chân trang chuyên nghiệp.

---

## 🚀 Hướng dẫn chạy
Mở file `index.html` trong trình duyệt web bất kỳ để trải nghiệm giao diện responsive hoàn chỉnh trên cả desktop và mobile.
