Thử Thách: Hamburger Menu Trên Mobile

Menu điều hướng này hoạt động 100% bằng CSS thuần (Pure CSS) kết hợp thủ thuật Checkbox (:checked) và Media Query mà không cần sử dụng bất kỳ dòng mã JavaScript nào.

Hướng dẫn kiểm tra:

  • Trên màn hình Desktop (≥ 768px): Menu hiển thị thanh ngang truyền thống, icon hamburger ẩn hoàn toàn.
  • Trên màn hình Mobile (< 768px): Menu ẩn đi, icon hamburger 3 vạch xuất hiện. Bấm vào icon để trượt mở menu xuống mượt mà.
