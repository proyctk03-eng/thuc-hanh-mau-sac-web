# [Thực hành] Tạo Trang Giới Thiệu Doanh Nghiệp với Bootstrap

Dự án thực hành xây dựng trang giới thiệu doanh nghiệp sử dụng các thành phần cốt lõi của **Bootstrap 5**:
- Navbar với menu điều hướng responsive (hamburger toggler).
- Hero Section mở đầu thu hút với tiêu đề và nút CTA.
- About Section giới thiệu thông tin công ty.
- Services Section chia 3 cột bằng Grid System (`col-md-4`) và Card components.
- Contact Section thông tin liên hệ.
- Footer hiển thị bản quyền.

---

## 🚀 Hướng dẫn chạy
Mở trực tiếp file `index.html` trong trình duyệt web bất kỳ để trải nghiệm giao diện responsive.
