Tiêu Đề Trang Web (External Style)

Đây là đoạn văn bản được định dạng màu sắc thông qua một tệp CSS độc lập (style.css) được liên kết qua thẻ <link>. Đây là tiêu chuẩn vàng trong thiết kế web hiện đại, giúp tách biệt hoàn toàn giữa cấu trúc HTML và thẩm mỹ giao diện.

📌 Ghi chú cú pháp: Đặt trong <head> <link rel="stylesheet" href="style.css"> </head>
