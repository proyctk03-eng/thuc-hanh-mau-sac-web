Minh họa trực quan 3 phương pháp nhúng định kiểu (Inline, Internal, External) và nguyên lý phân tầng ưu tiên (Cascade Specificity).

Phần 1: Inline Style Độ ưu tiên cao nhất

Tiêu Đề (Inline)

Đoạn văn có màu xanh lam đậm được áp dụng trực tiếp qua thuộc tính style.

<h1 style="color: #1D4ED8;">...</h1> <p style="color: #0369A1;">...</p>

Tiêu Đề (Internal)

Đoạn văn có màu xanh lục bảo định nghĩa trong thẻ <style> ở <head>.

<head> <style> h1 { color: #15803D; } p { color: #047857; } </style> </head>

Tiêu Đề (External)

Đoạn văn có màu tím hoàng gia được tải từ tệp độc lập style.css.

<head> <link rel="stylesheet" href="style.css"> </head>

⚡ Thứ Tự Ưu Tiên (CSS Cascading Order)

Khi cùng một phần tử HTML bị tác động bởi nhiều kiểu nhúng khác nhau, trình duyệt sẽ áp dụng quy tắc ưu tiên từ cao xuống thấp:

1. Inline Style Đè mọi quy tắc khác (trừ !important)
>
2. Internal / External Quy tắc nào được tải sau cùng sẽ ghi đè
>
3. Browser Default Kiểu mặc định của User Agent
