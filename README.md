# [Bài tập] Xây dựng bố cục trang web với display và inline-block

Dự án bài tập thực hành áp dụng thuộc tính `display: block`, `display: inline-block`, `width`, `max-width` để xây dựng bố cục trang web cơ bản.

---

## 📌 1. Mục tiêu bài tập
- Hiểu và ứng dụng `display: block` và `display: inline-block`.
- Thiết lập bố cục dạng cột ngang bằng `inline-block` kết hợp `width` và `margin`.
- Xây dựng thanh điều hướng `<nav>` với các thẻ liên kết `inline-block`.

---

## 📂 2. Cấu trúc thư mục

```text
bo_cuc_display_inline_block/
├── index.html       # File HTML chứa cấu trúc tiêu đề, thanh nav, section 3 cột và footer
├── style.css        # File CSS áp dụng display: inline-block và căn chỉnh bố cục
└── README.md        # Tài liệu hướng dẫn bài tập
```

---

## 🚀 3. Hướng dẫn chạy và xem trực tiếp
Mở file `index.html` trực tiếp bằng trình duyệt web bất kỳ hoặc sử dụng Live Server trong VS Code.
